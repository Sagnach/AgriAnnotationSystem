# AgriAnnotationSystem

AI-assisted agricultural image annotation system.

## Initial Target

Automatic apple instance detection, segmentation and annotation
using MinneApple and SAM 3 / SAM 3.1.

## Pipeline

Agricultural Image
-> SAM 3 / SAM 3.1
-> Automatic Instance Segmentation
-> Automatic Class Labelling
-> Human Review
-> Reviewed Annotation
-> COCO / YOLO-Seg Export

## Primary Dataset

MinneApple

## Initial Class

apple
